# Ameli Creaciones — versión demo estática

## Tecnologías
- HTML5
- CSS3
- JavaScript
- LocalStorage para el carrito de demostración

> No utiliza ningún motor, base de datos ni servidor backend.

## Cómo publicar en Github Pages
1. Se sube **todo el contenido de la carpeta del proyecto** a al repositorio de GitHub.
2. En el repositorio, se entra a **Settings → Pages**.
3. En **Build and deployment**, se selecciona **Deploy from a branch**.
4. Se selecciona la rama donde están los archivos y la carpeta `/ (root)`.
5. Guarda los cambios y espera a que GitHub Pages publique el sitio.

La página principal es `index.html`.

## Funcionalidad de demostración
- Navegación entre las vistas.
- Menú adaptable para móvil.
- Cambio de vistas por rol.
- Catálogo y filtros.
- Carrito mediante `localStorage`.
- Formularios y modales simulados.
- Pestañas, filtros y notificaciones.

## Importante
Esta es una **demostración frontend**. Las operaciones dependen de HTML/JavaScript "puro" para que el proyecto pueda ejecutarse en GitHub Pages.
